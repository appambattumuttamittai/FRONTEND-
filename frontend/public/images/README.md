## 🔄 How to Change an Image in the Future
1. Place your new image file directly inside this folder (`frontend/public/images/`).
2. Make sure it has the **exact same filename** (e.g. `logo.jpg` or `product-main.jpg`).
3. Deploy or restart — the website will immediately display the new image!
